# 🧾 Factures

Factures is a lightweight PHP-based web application for managing invoices. It allows users to create, view, and manage client invoices efficiently.

## 🚀 Features

- Create and download PDF invoices
- Manage client details
- Add services or products to invoices
- Store invoice history (optional with database)

## ⚙️ Tech Stack

- PHP
- HTML/CSS
- MySQL (optional)
- Bootstrap (optional for UI)

## 📦 Requirements

- PHP 7.x or higher
- Apache (recommended: XAMPP/LAMPP)
- MySQL (if using DB)
